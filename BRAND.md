# NETSIGHT Brand

## Identity

**Name:** NETSIGHT

**Meaning:** NET + SIGHT — visibility into what is moving across a network.

**Tagline:** **Know what's moving.**

**Brand promise:** Turn complex network activity into clear, useful information without hiding the technical depth.

## Personality

- Professional
- Precise
- Fast
- Calm
- Technical without being intimidating
- Transparent about what the analyzer can and cannot observe

## Visual language

NETSIGHT uses a dark, high-contrast technical foundation with an electric mint-to-blue accent. The visual system should feel like a modern observability tool rather than a generic cybersecurity product.

### Colors

| Token | Value | Usage |
|---|---|---|
| `ink-950` | `#0B1118` | Primary dark background / logo field |
| `ink-900` | `#111923` | Panels and surfaces |
| `text-100` | `#F5F7FA` | Primary text |
| `mint-500` | `#35F2C1` | Primary accent / active state |
| `blue-500` | `#4EA1FF` | Secondary accent / network data |

The mint-to-blue gradient is reserved for brand moments, selected visual highlights, and the logo. Do not use it on every UI element.

## Logo

The primary logo combines an eye with network paths and nodes. The eye represents visibility; the nodes and paths represent network traffic and connected devices.

- `assets/brand/logo.svg` — primary wordmark
- `assets/brand/logo-mark.svg` — standalone application mark
- `assets/brand/favicon.svg` — compact browser/app icon

### Clear space

Keep at least the height of the logo's central dot as clear space around the mark.

### Do not

- Stretch or distort the logo
- Add drop shadows to the supplied artwork
- Change the accent colors arbitrarily
- Place the dark logo on a dark surface without sufficient contrast
- Add extra symbols around the mark

## Typography

Preferred UI font stack:

`Inter, Segoe UI, Arial, sans-serif`

Use a strong weight hierarchy and generous spacing. NETSIGHT should feel dense in data views but spacious in navigation and onboarding.

## Product language

Use clear terms first, technical details second.

**Good:** `YouTube · HTTPS · 24.8 MB`

**Technical detail:** `TCP 443 · TLS · 142.250.x.x`

The product should never claim that it identified content it could not actually observe. When identification is uncertain, label it as `Unknown` or `Likely`.

## Core product modes

- **Network** — discover and inspect devices on the local network.
- **Traffic** — understand live traffic and service activity.
- **Packets** — inspect packet-level technical details.
- **Services** — group observable traffic by domains and services.

## Voice

Short, direct, confident. Avoid fear-based cybersecurity language. NETSIGHT is an observability and analysis tool, not a scareware product.
