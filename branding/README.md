# NetSight Brand System

## Positioning
NetSight is a Windows network observability tool: powerful packet intelligence presented as a calm, human-readable network view.

## Brand personality
- Precise, technical, trustworthy
- Calm under pressure
- Modern and focused, never gamer-like
- Dark-first with restrained luminous accents

## Palette
- Ink `#07111F` — app background
- Navy `#0D1B2A` — surfaces
- Slate `#17283B` — elevated surfaces
- Signal Cyan `#22D3EE` — primary brand/action
- Signal Blue `#3B82F6` — secondary data accent
- Electric Violet `#8B5CF6` — correlation/intelligence accent
- Success `#34D399`
- Warning `#FBBF24`
- Danger `#FB7185`
- Text `#F4F7FB`
- Muted `#8FA2B8`

## Logo rules
Use `assets/netsight-logo.svg` as the canonical mark everywhere. Do not redraw or recolor the mark outside the approved palette. The same source SVG is used by the application header, empty states, splash/branding surfaces and icon source.

## Product UI direction
Dark-first, high-contrast, glass-like surfaces, thin borders, subtle cyan/violet glow, dense data tables with generous hierarchy. The UI should feel closer to a professional observability console than a legacy packet analyzer.
